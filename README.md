# FPBCRAFT CC:Tweaked scripts

ComputerCraft/CC:Tweaked programs for the fpbcraft Minecraft server.

- [Skyways airship autopilot](airship/README.md) — Basalt 2.5 touchscreen flight dashboard, animated airship startup, route/preset management, optional engine control, and a one-command installer (`install-airship.lua`).
- See [`factory/README.md`](factory/README.md) for the Basalt 2.5 factory controller, installation and machine configuration.
- [TIDEBOUND: The Shattered Expanse](tidebound/README.md) — four-civilization, 1–4 player touchscreen 4X with local AI, diplomacy, narratives and legacy games, installed with `install-tidebound.lua`.
- [COGWORKS: Kinetic Lab](cogworks/README.md) — 12 inventory-limited machinery construction puzzles with animated CC: Graphics, a text fallback, hints and a safe one-command installer (`install-cogworks.lua`).
- [RAILBREAK: Kinetic Frontier](railbreak/README.md) — solo/1–4-player Create-inspired turn-based railway and factory roguelite with functional kinetics, conveyors, production and contracts; installed with `install-railbreak.lua`.

All factory controls must retain a physical manual override. Do not rely on software alone for machinery safety.
